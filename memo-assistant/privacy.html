プライバシーポリシー

メモアシスタント（以下「本アプリ」）　制定 2026年10月27日

本アプリは、開発者である今井泰斗が自分ひとりで使うために作ったアプリです。他の人に配布・提供しておらず、利用者は開発者本人だけです。

1. 扱う情報

  • 利用者が入力した ToDo・メモの内容、期限・リマインドの日時、並び順
  • ログイン用のメールアドレス
  • 利用者が Google 連携を許可した場合に限り、Google カレンダーの予定、Gmail のメール、Google ドライブのファイル情報（下記「4」）

2. 保存する場所

  • ToDo・メモは、利用者の端末と、端末間の同期のために利用者自身が管理する Supabase のデータベースに保存します。
  • 毎晩のバックアップを、利用者自身の Google ドライブに保存します。
  • Google の認証情報（トークン）は利用者の端末の中にだけ保存し、外部へ送りません。

3. AI（アシスタント）への送信

アシスタント機能を使ったときに限り、質問への回答に必要な範囲の情報（ToDo・メモ、今日の予定、利用者が調べるよう頼んだメールやファイルの内容）を Anthropic 社の Claude API に送ります。送信には利用者自身の API キーを使います。

4. Google のユーザーデータの利用

  • Google カレンダー：予定を読んで回答や画面表示に使います。予定の追加は、利用者が頼んだときだけ行います。
  • Gmail：利用者が頼んだときにメールを検索・閲覧するだけです。送信・削除・既読化・設定変更は行いません。
  • Google ドライブ：ファイルの検索と、本アプリのバックアップファイルの保存に使います。
  • Google から受け取った情報は、上記の機能を利用者本人に提供するためだけに使い、広告への利用、第三者への販売・譲渡、人による閲覧は行いません（上記「3」のとおり、利用者がアシスタントに頼んだ場合の Claude API への送信を除きます）。
  • 本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

5. 第三者への提供

上記「2」「3」の保存・処理の委託先（Supabase、Google、Anthropic）を除き、情報を第三者に提供しません。

6. 削除

本アプリの設定画面から Google 連携を解除すると、端末内の Google の認証情報を消し、許可を取り消します。Google アカウントの「サードパーティのアクセス」からも、いつでも取り消せます。ToDo・メモはアプリ内で削除できます。
